## 目前內容

啟動與定時檢查的 Codex 資料來源維持本機 session 事件；手動刷新可透過 Codex app-server 取得帳戶即時資料。即時查詢失敗時必須退回本機 session，且畫面需告知使用者目前顯示的是 LOG fallback。

手動刷新不得改變每 30 秒自動檢查的行為。Claude 自動檢查沿用 5 分鐘快取；手動刷新改用 Claude Code CLI `/usage`，失敗時才退回既有資料來源。

成功取得的 Claude 手動即時值必須寫回記憶快取，避免下一次 30 秒自動檢查立刻覆蓋畫面。自動 API 暫時失敗時應保留最後一筆成功快取，不可將可用資料替換成錯誤狀態。

Codex 手動即時結果同樣保留 5 分鐘。排程仍須每 30 秒讀取本機 LOG，但在即時快取有效期間不得以較舊的 LOG 覆蓋畫面；快取到期後恢復顯示排程讀取結果。

## 2026-06-08 視窗停靠規則

Widget 的主要定位規則是靠近 Windows 時間與通知區，但不得覆蓋工作列。定位需使用 Electron `screen` 的 `workArea` 計算，避免在不同解析度或工作列高度下超出可用工作區。

從系統列叫出 Widget 時，應優先停靠到滑鼠所在螢幕的右下角；啟動與螢幕工作區變動時，則以主螢幕工作區重新計算位置。
